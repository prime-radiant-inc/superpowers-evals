# Constructed evidence control

This is curator-authored dialogue and delivery for an offline assessment control.
It is not a live conversation, a native agent session, or a captured terminal.
Files under `execution/` are actual local command receipts generated by the
curator against the included source. Their exit statuses and output are observed;
the role dialogue is constructed. No provider or application service was called.
The evidence index lists the entire constructed dialogue, delivery, source and
applicable receipts. No other conversation or delivery is omitted.
